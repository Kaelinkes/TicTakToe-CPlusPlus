# TicTacToe-CPlusPlus

## 📘 Overview
A console-based Tic-Tac-Toe game written in C++ where two players alternate turns on a 3×3 board until one wins or it’s a draw.  
Built as a practice project to demonstrate C++ fundamentals and good programming structure.

## 🎯 Features
- Two-player mode (no AI)  
- Display of board state after each move  
- Input validation (ensuring valid moves)  
- Win/loss/draw detection logic  
- Clean, modular C++ code (functions for display, input, checking win, etc.)

## 🧩 Why I Built It
- To practice C++ syntax, control structures, arrays and functions  
- To create a simple, complete project you can compile and run  
- To demonstrate my coding style and structure for learning and portfolio purposes  

## 🚀 Getting Started

### Prerequisites
- A C++ compiler (e.g., g++, clang, MSVC)  
- Basic familiarity with command-line compilation
